# An AI analyst for your data
Ever needed to know info about your data without manually calculating.

## What you need ?
- A CSV (or excel) file having your data
- LLM keys (if you have)


## What it can do ?
- Ask statistical questions about the data
- Infer information from the data
- Perform calculations based on the data
  
## What it can't ?
- Don't ask too many questions at once.
- Don't ask very complex questions
- The ability of the agent to solve depends upon the LLM used underneath as well
